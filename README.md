# 部活会計

ソフトテニス部の会計（部費の割り勘と精算）を計算するアプリです。会計係が1人で使う前提です。

## 起動のしかた

```
npm install      # 初回だけ
npm run dev      # ブラウザで表示されたURLを開く
```

データはインターネットに送られず、**開いたブラウザの中にだけ**保存されます。
PCやブラウザを変えるとデータは見えません。

## 毎年の流れ

1. **名簿**タブ →「継続届から読み込む」で、その年の継続届（.xlsx）を選ぶ
   - 学籍番号で同じ人を見分けます。学年は自動で上がり、設定した性別は残ります。
   - 新しく入った人は性別を選びます（継続届に性別がないため）。「全員を男にする」で揃えてから、違う人だけ直すと早いです。
   - 継続届にいない人は「OB」「退部」「在籍のまま」から選びます（4年生以上はOBが初期値）。
2. **会計**タブ → 会計を名前だけで作る（例：「夏合宿まで」）。年4回ほど。
3. 会計の中で、車の移動ごとに「乗った人」と「運転手」にチェック
4. 支出を入力する
   - **高速・ガソリン**：その移動に乗った人から、運転手を除いた人数で割ります
   - **雑費**（それ以外すべて）：対象の部員全員で割ります。学年・性別で絞ったり、個別に選んだりもできます
   - 立て替えた人を選ぶと、その人に返す金額も計算されます
5. 精算結果を「印刷 / PDFで保存」して、部員に見せる証拠として残す

部費から払ったものや、会計の区切りに関係ない支出は「通年（全期間）」に入れます。
「全期間の集計」タブで、まだ精算していない金額をまとめて見られます。

## 部員の状態

- **在籍**：新しい会計の対象になる
- **OB / 退部**：新しい会計の対象から外れる。過去の会計の記録はそのまま残る
  （OBが合宿に来たときは、会計画面の「退部・OBの人も表示する」から乗車や対象にできます）
- **削除**：名簿から完全に消します。その人が立て替えた支出は「部費から支払い」に変わり、割り勘の金額も変わります。記録を残したいなら削除ではなくOB・退部にしてください。

## 引き継ぎ

1. 「バックアップ」タブ →「バックアップを書き出す」で .json ファイルを保存し、次の会計係に渡す
2. 次の会計係は、自分のPCでアプリを開いて「バックアップ」タブ →「バックアップから復元」でそのファイルを選ぶ

ブラウザのデータを消すと記録も消えるので、会計のたびにバックアップを書き出しておくと安心です。

## 開発者向け

```
npm run check                                  # 精算ルールの確認（src/settle-probe.ts）
node sample/roster-probe.ts <継続届.xlsx>       # 継続届の読み込み確認
node sample/make-sample.ts                     # sample/テストデータ.json を作り直す
npm run build                                  # dist/ に出力
```
