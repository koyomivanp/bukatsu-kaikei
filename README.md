# 部活会計

ソフトテニス部の会計（部員が立て替えたお金の割り勘と精算）を計算するアプリです。会計係が1人で使う前提です。

初めて開いたときは「サンプルデータで試す」で、架空の部活のデータを入れて画面を試せます。試し終わったら、画面上の「サンプルを消して始める」で空の状態に戻ります。

## 開きかた

**https://koyomivanp.github.io/bukatsu-kaikei/** をブラウザ（PCのEdge・Chromeなど）で開くだけです。インストールは要りません。

データはサーバーに保存されず、**開いたブラウザの中にだけ**保存されます（AIの読み取りを使ったときだけ、貼り付けた文章やレシート画像が読み取りのため Anthropic に送られます）。
PCやブラウザを変えるとデータは見えません。

## 毎年の流れ

1. **名簿**タブ →「継続届から読み込む」で、その年の継続届（.xlsx）を選ぶ
   - 学籍番号で同じ人を見分けます。学年は自動で上がり、設定した性別は残ります。
   - 新しく入った人は性別を選びます（継続届に性別がないため）。「全員を男にする」で揃えてから、違う人だけ直すと早いです。
   - 継続届にいない人は「OB」「退部」「在籍のまま」から選びます（4年生以上はOBが初期値）。
2. **会計**タブ → 会計を名前だけで作る（例：「夏合宿まで」）。年4回ほど。
   4年生以上は最初は参加者に入らないので、参加する人だけ名前を押して入れます。
3. 「参加者と車」で参加者と、車に乗った人・運転した人を選ぶ（名前を押して切り替え。最初は参加者全員が乗っていることになっています）
4. 支出を入力する。どの支出も、部員の誰かが立て替えて後で精算する前提です
   - **高速・ガソリン**：運転した人を選びます。運転した人がそのまま立て替えた人になり、乗った人から運転手を除いた人数で割ります。
     立て替えた人が違うときは「運転した人と立て替えた人が違う」にチェックして選びます
   - **雑費**（それ以外すべて）：イベント参加者で割ります。学年・性別で絞ったり、個別に選んだりもできます
   - 一人ひとりが会計に払う金額・会計から受け取る金額が計算されます。「文章をコピー」で、そのまま部のLINEに貼れる一覧になります（精算済みにした人は載りません）
   - 合宿などで車が何台・何回にも分かれ、乗る人が違うときは「＋ 車を追加」で分けられます。運転した人を選ぶ欄が車ごとに分かれます
   - 合宿費などを先に集めた・集めたお金から返したときは「集金・返金」に記録します。集めすぎた分は精算結果の「受け取る」に出てきます
   - 部員に LINE で「高宮車 高速 2000円」「花火 3280円」のように送ってもらえば、その文章をコピーして「メッセージから追加」に貼るだけで支出に分けられます（下の「AIの読み取り」）
   - レシートの写真や PDF を「レシート」から読み込むと、AI が金額を読み取り、同じ金額の支出に証拠として結びつけます
5. 精算結果を「印刷 / PDFで保存」して、部員に見せる証拠として残す

会計の区切りに関係ない支出（ボールなど）は「通年（全期間）」に入れます。年度の初めに集金して、年度末に余りを返す使い方を想定しています。
「まとめて集計」タブでは、選んだ会計をまとめて精算できます（通年は最初は外れています）。
同じタブの「支出の内訳」は、部員に説明するための書き出しです。選んだ会計の支出を「何にいくら・誰が立て替え・何人で割って1人いくら」の形で並べ、
「文章をコピー」で LINE に貼るか、「内訳だけ印刷 / PDF」で PDF にできます（一人ずつの負担額を載せるかも選べます）。

## AIの読み取り

- 使うには Claude の APIキーが必要です（[Anthropic Console](https://console.anthropic.com/settings/keys) で作成。1回あたり数円以下が目安）
- キーは会計画面の「AIの設定」に貼ります。このブラウザにだけ保存され、バックアップには入りません。引き継ぐときは次の人が自分のキーを作ってください
- 貼り付けた文章やレシート画像は、このPCから Anthropic に直接送られて読み取られます

### メッセージから追加

- LINE のトークやノートの文章をコピーして貼ると、AI が支出ごとに分けます。雑談や返事は無視し、訂正があれば訂正後の内容にします
- 「〇〇車」は〇〇が運転した車です。立て替えた人は「〇〇払い」とあればその人、なければ送った人（高速・ガソリンは運転した人）になります
- 追加する前に一覧で確認します。名簿の誰か決まらない名前（LINEの表示名がニックネームなど）や、どの車か決まらないものは、その行で選びます
- 同じ費目・金額・立て替えた人の支出がすでにあるものは「すでにあるかも」として、最初はチェックを外しています
- 部員への頼み方の例：「1件1メッセージで、高速・ガソリンは『誰の車・何・金額』、それ以外は『何・金額』。人の分を払ったときだけ『〇〇払い』と書いてください」

### レシート

- レシートは証拠として、同じ金額の支出に結びつけるだけです（支出を作ったり変えたりはしません）。金額が1つに決まらないものは手で選びます
- iPhone の写真（HEIC）は読めないので、JPEG で保存し直すかスクリーンショットにしてください

## 部員の状態

- **在籍**：新しい会計の対象になる
- **OB / 退部**：新しい会計の対象から外れる。過去の会計の記録はそのまま残る
  （OBが合宿に来たときは、会計画面の「退部・OBの人も表示する」から参加者や乗車にできます）
- **削除**：名簿から完全に消します。その人が立て替えた支出は立て替えた人が未選択になり（選び直すまで精算に入りません）、割り勘の金額も変わります。記録を残したいなら削除ではなくOB・退部にしてください。

## 引き継ぎ

1. 「バックアップ」タブ →「バックアップを書き出す」で .json ファイルを保存し、次の会計係に渡す
2. 次の会計係は、自分のPCでアプリを開いて「バックアップ」タブ →「バックアップから復元」でそのファイルを選ぶ

ブラウザのデータを消すと記録も消えるので、会計のたびにバックアップを書き出しておくと安心です。書き出していない変更が3日以上前からあると、画面の上にお知らせが出ます。

## 開発者向け

```
npm run check                                  # 精算ルールの確認（src/settle-probe.ts）
node sample/roster-probe.ts <継続届.xlsx>       # 継続届の読み込み確認
node sample/make-sample.ts                     # sample/テストデータ.json を作り直す
npm run build                                  # dist/ に出力
```
